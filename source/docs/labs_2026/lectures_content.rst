Краткий конспект лекций
=======================

.. contents:: Содержание:
    :local:
    :depth: 2

Лекция 1. Установочная встреча
-------------------------------

Знакомство с преподавателем. Общая структура курса. Формирование
итоговой оценки. Основные идеи, закладываемые в курс. Место курса в
образовательной программе.

Лекция 2. Общая информация о Python. Числа
-------------------------------------------
Историческая справка о языке Python. Семантическое версионирование.
Проблемы перехода между мажорными версиями. Преимущества языка.
Способы повышения скорости работы программы. Форматы запуска программ: репл, консоль.
Объектная модель. Сборщик мусора. Переменная как ссылка. Числовые типы.
Особенности создания целых чисел и чисел с плавающей точкой.
Точность при работе с числами с плавающей точкой.
Арифметические операторы и приоритеты. Неизменяемость.

Лекция 3. Тип bool. Условия
----------------------------

Тип bool. Специальные значения True и False. Истинность контейнеров.
Структура ``if/elif/else``. Приведение выражения в условии к типу ``bool``.
Объединение нескольких условий. Отложенная оценка. Функции ``all()``, ``any()``.
Тип bool как наследник типа int. Сравнение объектов: ``==`` и ``is``.
Сравнение с True/False и None. Тернарный оператор.

Лекция 4. Последовательности. Тип str
--------------------------------------

Последовательности в ``Python``: ``str``, ``list`` и ``tuple``. Ключевые
свойства последовательностей. Индексируемость. Срезы: особенности
использования, синтаксиса. Срезы как способ копирования
последовательностей. Итерируемость. Варианты обхода последовательности:
по элементам, по индексам (``range``), одновременно по индексам и
значениям (``enumerate``). Взятие длины последовательности. Проверка на
вхождение. Получение минимального и максимального элементов. Подсчет
количества вхождений элемента. Получение индекса первого вхождения
элемента по его значению. Строковые методы. Особенности использования
методов ``split``, ``join``. Структура ``for/else``.

Лекция 5. Списки
-----------------

Способы создания списков. Изменяемость списков: добавление, удаление и
изменение существующих элементов. Срезы как способ поверхностного
копирования. Ловушка разделяемых ссылок. Глубокое копирование.
Преимущества и недостатки различных способов копирования. Списочные выражения.
Основные преимущества списочных выражений. Списочное выражение как фильтр данных.

Лекция 6. Кортежи
------------------

Способы создания кортежей. Структурная неизменяемость кортежей. Основные
сценарии использования кортежей. Распаковка значений кортежа. Сортировка списков
и кортежей через функцию ``sorted``. Лямбда-функция для сортировки наборов сложных
объектов.

Лекция 7. Словари.
------------------

Способы создания словарей. Разница в поведении оператора квадратные
скобки при извлечении значений в словаре и списке. Изменяемость
словарей. Добавление новых элементов в словарь. Удаление элементов из
словаря. Изменение существующих элементов. Уникальность ключей.
Требования к ключам словаря. Итерирование по ключам, значениям и парам,
хранящимся в словаре. Проверка на вхождение ключа с помощью оператора
``in``. Получение размера словаря с помощью ``len()``. Словарные выражения.

Лекция 8. Множества. Функции.
-----------------------------

Способы создания множеств. Включения для множеств. Проверка на вхождение
элемента с помощью оператора ``in``. Получение размера множества с помощью ``len()``.
Итерирование по множествам. Изменяемость множеств. Операции над множествами
как математическими абстракциями. Объявление функции с помощью ``def``. Требования и рекомендации к
именованию функций. Аргументы функции: позиционные и именованные.
Опциональные подсказки типов в описании аргументов и возвращаемых
значений. Вызов функции и её объявление. Возврат результатов функции с
помощью ``return``. Возврат и обработка нескольких значений.
Сопоставление аргументов при вызове функции: позиционное и по имени.
