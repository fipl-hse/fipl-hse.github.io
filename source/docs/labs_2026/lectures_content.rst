Лекция 1. Установочная встреча.
-------------------------------

Знакомство с преподавателем. Общая структура курса. Формирование
итоговой оценки. Основные идеи, закладываемые в курс. Место курса в
образовательной программе.

Лекция 2. Установочная встреча. Общая информация о Python. Числа.
-------------------------------------------------------------------
Историческая справка о языке Python. Семантическое версионирование. Проблемы перехода между мажорными версиями. Преимущества языка. Способы повышения скорости работы программы. Форматы запуска программ: репл, консоль. Объектная модель. Сборщик мусора. Переменная как ссылка. Числовые типы. Особенности создания целых чисел и чисел с плавающей точкой. Точность при работе с числами с плавающей точкой. Арифметические операторы и приоритеты. Неизменяемость.

Лекция 3. Тип bool. Условия.
----------------------------

Тип bool. Специальные значения True и False. Истинность контейнеров. Структура if/elif/else. Приведение выражения в условии к типу bool. 
Объединение нескольких условий. Отложенная оценка. Функции all(), any(). 
Тип bool как наследник типа int. Сравнение объектов: == и is.
Сравнение с True/False и None. Тернарный оператор.
