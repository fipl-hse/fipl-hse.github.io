Лекция 1. Установочная встреча

Знакомство с преподавателем. Общая структура курса. Формирование итоговой оценки. Основные идеи, закладываемые в курс. Место курса в образовательной программе.

Лекция 2. Общая информация о Python. Числа

Историческая справка о языке Python. Семантическое версионирование. Проблемы перехода между мажорными версиями. Преимущества языка. Способы повышения скорости работы программы. Форматы запуска программ: репл, консоль. Объектная модель. Сборщик мусора. Переменная как ссылка. Числовые типы. Особенности создания целых чисел и чисел с плавающей точкой. Точность при работе с числами с плавающей точкой. Арифметические операторы и приоритеты. Неизменяемость.

Лекция 3. Тип bool. Условия

Тип bool. Специальные значения True и False. Истинность контейнеров. Структура if/elif/else. Приведение выражения в условии к типу bool. Объединение нескольких условий. Отложенная оценка. Функции all(), any(). Тип bool как наследник типа int. Сравнение объектов: == и is. Сравнение с True/False и None. Тернарный оператор.

Лекция 4. Последовательности. Тип str

Последовательности в Python: str, list и tuple. Ключевые свойства последовательностей. Индексируемость. Срезы: особенности использования, синтаксиса. Срезы как способ копирования последовательностей. Итерируемость. Варианты обхода последовательности: по элементам, по индексам (range), одновременно по индексам и значениям (enumerate). Взятие длины последовательности. Проверка на вхождение. Получение минимального и максимального элементов. Подсчет количества вхождений элемента. Получение индекса первого вхождения элемента по его значению. Строковые методы. Особенности использования методов split, join. Структура for/else.

Лекция 5. Списки

Способы создания списков. Изменяемость списков: добавление, удаление и изменение существующих элементов. Срезы как способ поверхностного копирования. Ловушка разделяемых ссылок. Глубокое копирование. Преимущества и недостатки различных способов копирования. Списочные выражения. Основные преимущества списочных выражений. Списочное выражение как фильтр данных.

Лекция 6. Кортежи

Способы создания кортежей. Структурная неизменяемость кортежей. Основные сценарии использования кортежей. Распаковка значений кортежа. Сортировка списков и кортежей через функцию sorted. Лямбда-функция для сортировки наборов сложных объектов.
