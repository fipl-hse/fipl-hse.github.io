Lecture 1. Modern NLP Tasks

Introduction of the instructor. General course structure. Formation of the final grade. Core ideas behind the course. The place of the course in the degree programme. Structure of the laboratory work. LLM. Typical NLP tasks solved with neural network models. Model lifecycle: pre-training, inference, fine-tuning, inference. Tokenization as a way to move from text to numeric form and back. Fundamental relationship between the tokenizer and the model. Model vocabulary. Main criteria when choosing a model: quality of solving the task and the amount of computational resources required.

Lecture 2. Inference

Inference as a forward pass with fixed weights. Difference between inference and training: loss, backward pass, and weight update. Inference pipeline: text, tokens, IDs, forward pass, logits, probabilities, one class or one token. Tokenization in practice: vocabulary, token versus word, byte-pair encoding (BPE), encoding and decoding, padding, truncation, max length, and special tokens. Logits and softmax. Generation as repeated classification over tokens. Greedy decoding and sampling with temperature. Prefill and decode phases, TTFT and tokens/s.

Lecture 3. Batch Inference

Batch inference as data organization: one sample and one batch; samples remain independent and each gets its own prediction. Sample inference as a special case of a batch with size 1. Batch size and number of model calls. Throughput versus latency; limits of large batches; variable-length samples, truncation and padding; one input tensor, logits, row-wise softmax and argmax. Dataset structure, splits and data quality; task-specific dataset and metric. Classification metrics: Accuracy, F1. Generation metrics: BLEU, ROUGE-L; token Accuracy is not a generation metric. Generation as iterative classification over the vocabulary; greedy, top-k and top-p; renormalization.
